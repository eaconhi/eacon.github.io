# 小 P 音乐

独立于既有 Vue 壁纸与海拔模块的浏览器音乐组件。入口为 `window.XPMusic.open()`，也响应 `xp:open-music`。

## 编辑与发布

- `app.js`：曲库、搜索、播放队列、收藏、本地导入、账号与缓存界面。
- `core.mjs`：偏好校验、LRC / 增强 LRC / TTML / 明文 KRC 时序和 IndexedDB。
- `style.css`：8 种播放器、10 种主题色、4 种歌词方式；Shadow DOM 隔离样式。
- `node scripts/build-music.mjs`：生成带内容指纹的公开资源并更新 `/xp/index.html` 与离线清单。
- `npm run test:music`：逻辑与平台契约测试。
- `npm run build`：重新生成组件，并构建原有 GitHub Pages 网站。

生产入口仍为 `https://xpeng.win/xp/`，音乐服务为 `https://music.xpeng.win`。播放器在原生全屏切换时跟随全屏元素。关闭曲库不停止播放；关闭显示开关只隐藏壁纸组件。

## 数据

曲库与音频缓存保存在 `xp-music-v1` IndexedDB，显示设置使用独立的 `xp-music-*` 键，不清理或更改壁纸、传感器配对和原有身份。缓存只在完整播放后或手动操作时写入，按容量淘汰较早内容；本地导入与收藏独立保留。离线播放优先使用已缓存 Blob。浏览器仍可能主动回收存储。

Navidrome 凭据仅保留在当前页面内，不写入曲库、封面元数据或本机设置。其 HTTPS 服务器需要允许浏览器跨域访问。刷新后需重新连接。

## 平台边界

- 酷狗：公开曲库搜索、平台返回的播放地址及歌词。受限曲目保留原平台限制。
- QQ 音乐：MIT 许可的 `@yakult-green-tea/qq-music-api@3.3.3`；扫码后才使用用户账号。浏览器保存不透明会话令牌，未实施账号歌单写入操作。
- 汽水音乐：MIT 许可的 `qishui-music-api@0.2.2`。专用 Durable Object 保存用户主动扫码授权的会话，页面只接收签名的对象引用。仅开放读取、播放、扫码和退出，不解密受保护音频。试听片段保留标志与歌词起点。
- 网易云：公开接口适配保留；当前云端搜索可能返回 `-462` 风控拒绝，界面明确显示失败，不将其当成“没有歌曲”。没有绕过平台限制或替代为其他平台歌曲。

内置氛围曲目复用站点已部署的 Chris Zabriskie CC BY 4.0 音频，并在曲库标注作者与许可。没有复制原站的编译包或 Folia 源码。

## 验证说明

浏览器检查涵盖实际音频播放、酷狗搜索与播放、歌词导入、8 种布局与4种歌词选择、移动端布局、缓存和离线播放。合成音频和测试歌词只用于本地 QA。账号扫码成功、账号曲目权限和 XOS 车机实播需要用户在真实设备完成授权后确认，不从页面或接口成功推定。
