# Resume Parallax Implementation Plan

> **For agentic workers:** Implement the authorized plan task by task with available tools. Optional execution skills may help but are not prerequisites. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add reversible, scroll-scrubbed depth to the existing bilingual resume.

**Architecture:** A long section contains a sticky viewport. A pure progress model drives portrait, typography and three content chapters through CSS variables; one pending animation frame batches updates. Native scrolling and direct navigation remain available.

**Tech Stack:** Existing Next.js 14, React 18, TypeScript and CSS. No added runtime dependency.

## Global Constraints

- Base: GitHub main cb3625a, preserving current AI operations positioning and orange/black identity.
- Preserve profile facts, portrait, bilingual data, project disclosures, shared access form and resume assets.
- No video asset was supplied. Use the existing portrait and typography as independent depth layers; this adapts the reference's scroll-controlled motion, not its video content.
- Honor reduced motion and short viewports; restore a complete natural-flow layout with no spacer.
- Prepare a local preview and verified build. Publishing the public GitHub Pages site requires the user's publication authorization.
